System Requirements

Before running Dragger AI, ensure your system meets the following specifications for optimal performance.

Python 3.10 or higher
Windows 10 / 11 (64-bit)
Active Internet Connection for API calls

Installation Guide

Step 1: Install Dependencies

pip install -r requirements.txt

Step 2: Run Dragger AI

python main.py

Tip: If you're using the standalone version, simply double-click DraggerAI.exe.

How to Use Dragger AI

Master the experience in three simple steps.

1. Trigger

Press CTRL + SHIFT + A to start. The screen will dim, and your mouse becomes a selection tool.

2. Capture

Drag your mouse to select exactly what you want the AI to see. Release to finish the capture.

3. Analyze

Type your question or request in the popup box. High-speed AI will provide the answer in seconds.

Getting your API Keys

Config Walkthrough

  • 1 Visit the provider console using the links provided.
  • 2 Click "Create New Key" and copy it to your clipboard.
  • 3 In Dragger AI, open the Control Panel, paste the key, and click Save.
