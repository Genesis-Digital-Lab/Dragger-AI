# AI Screenshot Copilot 🚀

A high-performance Windows application that captures your screen and uses state-of-the-art AI (Gemini, OpenAI, Anthropic) to analyze images, solve problems, or explain content instantly.

## 🌟 Ready to Use
You can use the application directly without installing Python!

1. **Launch**: Double-click **`AICopilot.exe`** in this folder.
2. **Set Up**: 
   - When the Control Panel opens, enter your **API keys** for Google, OpenAI, or Anthropic.
   - Click **Save** (it will remember your keys safely).
   - Click **Start Service**.
3. **Capture**: Press **`Ctrl+Shift+A`** (default) anytime to drag and capture a portion of your screen for AI analysis.

## 🛠️ Advanced Usage (Developers)
If you prefer to run from source code:
1. Install dependencies: `pip install -r requirements.txt`
2. Run: `python main.py`
